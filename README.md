# 青年委員 応援カレンダー

倫理法人会の講話・モーニングセミナーの予定を共有し、参加表明と登壇者への応援メッセージを送れる Web ページです。

## 構成（スプレッドシート版）

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体（GitHub Pages で公開） |
| `config.js` | Apps Script のウェブアプリ URL を設定するファイル |
| `gas/Code.gs` | Google Apps Script。スプレッドシートの読み書きとリマインドメール送信 |
| `gas/appsscript.json` | Apps Script の設定（タイムゾーン・権限） |
| `SETUP.md` | 初回の設定手順 |
| `artifact/index.html` | 旧版（claude.ai 版。https://claude.ai/artifact/GCe64RuSzaueWQyv4hSy5C ） |

データはすべて Google スプレッドシート（「予定」「参加者」「応援メッセージ」シート）に保存されます。

## 機能
- 最初の画面に「これからの予定」を横長の一覧で表示（日付・時刻・単会名・講話者・会場）。タップで詳細へ移動
- 月間カレンダーは下部の「カレンダーで見る」から開けます
- 各回に「地図を開く」（Google マップ）と「Googleカレンダーに登録」ボタン
- 「参加する」ボタンで名前付き参加表明。メールアドレス（任意）を入れると前日にリマインドメールが届きます
- 登壇者ごとに応援メッセージ（本文＋書いた人の名前）を投稿し、掲示板形式で表示（登壇者で絞り込み可）
- 「一括コピー（LINE用）」で、その回の応援メッセージを登壇者ごとにまとめた文章としてコピー
- 自分が登録・投稿したものは、同じ端末から取り消し可能
- 参加人数や応援件数は表示しません。ページ上に予定の削除機能はありません

## 予定の更新
スプレッドシートの「予定」シートを直接編集します（詳しくは `SETUP.md` の「ふだんの運用」）。
Claude Code に依頼する場合は、追加したい予定の文章を渡すと「予定」シートに貼れる形に整えます。

## プライバシー
- メールアドレスはスプレッドシートにだけ保存し、ページには返しません
- 削除キーもページには返さず、登録した端末にだけ保存します
